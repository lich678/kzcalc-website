# KzCalc — Online Calculators for Kazakhstan

**Website: [KzCalc.com](https://kzcalc.com/)**

KzCalc is an independent website with free online calculators for everyday financial and household questions in Kazakhstan. It offers Russian, Kazakh and English interfaces, with tools for 2026 salary estimates, teacher pay, MRP/MCI conversions and family welfare self-assessment.

Use the calculators on the website without creating an account. Each calculator page explains its inputs, calculation approach, sources and limitations. This repository introduces the website and helps visitors find the right tool.

## How to use KzCalc

1. Choose a tool and language in the table above.
2. Enter the details relevant to your situation and review the result breakdown.
3. Read the page's sources and limitations before using the estimate in a payroll or household decision.

Calculations are estimates within the supported inputs. KzCalc is not a government service, and a family category estimate does not determine benefit eligibility or replace an official assessment.
